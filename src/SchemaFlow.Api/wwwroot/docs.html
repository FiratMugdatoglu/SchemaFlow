Getting Started with SchemaFlow

SchemaFlow is a zero-knowledge database migration risk detector, ER diagram generator, linter, and seed data engine. It parses your migration files (C# EF Core, Prisma, PostgreSQL, MySQL, Django, Rails) completely offline on your machine—without connecting to live production databases.

1 Installation (Global .NET CLI Tool)

Install SchemaFlow globally on your machine with one command via NuGet:

dotnet tool install -g SchemaFlow

Requires .NET 9.0 SDK or Runtime. To verify installation, run: schemaflow --help.

2 Core CLI Commands & Workflows

schemaflow generate Visual ERD & Data Dictionary

Parses your migration files into a professional Markdown data dictionary and opens an interactive pan/zoom ER diagram in your browser:

# .NET Entity Framework Core (.cs is auto-detected!)
schemaflow generate -i ./Migrations/InitialCreate.cs -o ./docs/database.md --open

# TypeScript Prisma (.prisma)
schemaflow generate -i ./prisma/schema.prisma -o ./docs/database.md --open

# PostgreSQL / MySQL / Supabase (.sql)
schemaflow generate -i ./database/schema.sql -o ./docs/database.md --open

💡 Passing --open automatically pops up your browser with an interactive SVG diagram canvas and searchable data dictionary.

schemaflow diff Breaking Change Detector

Compares two schema versions, flags dangerous destructive changes (dropped columns, data type narrowing), and opens side-by-side Before/After visual schemas:

# Compare versions and launch side-by-side visual comparison in browser
schemaflow diff -b ./v1_schema.sql -t ./v2_schema.sql -o ./diff_report.md --open

# Fail CI/CD build with exit code 1 if breaking changes exist
schemaflow diff -b ./v1_schema.sql -t ./v2_schema.sql --fail-on-breaking

schemaflow lint Schema Health & Anti-Pattern Audit

Audits schemas for missing Primary Keys (SF001), unindexed Foreign Keys (SF002), and reserved SQL keywords (SF003). Computes a 100-point Health Score and provides 1-click ready SQL fixes:

schemaflow lint -i ./schema.sql --open

schemaflow seed Smart Relational Test Data

Solves topological Foreign Key hierarchies to generate valid relational test SQL inserts without constraint violations:

# Generate 10 matched mock rows per table
schemaflow seed -i ./Migrations/InitialCreate.cs -n 10 -o seed.sql

3 Automated GitHub Actions PR Safety Bot

Add SchemaFlow to your repository (.github/workflows/schemaflow.yml) to automatically audit migrations and comment on Pull Requests:

name: 'SchemaFlow Migration Safety Check'

on:
  pull_request:
    paths:
      - '**/Migrations/**'
      - '**/*.sql'
      - '**/*.prisma'

permissions:
  contents: read
  pull-requests: write

jobs:
  migration-safety:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0

      - name: Setup .NET
        uses: actions/setup-dotnet@v4
        with:
          dotnet-version: '9.0.x'

      - name: Install SchemaFlow
        run: dotnet tool install -g SchemaFlow

      - name: Audit Migration Health
        run: schemaflow lint -i ./schema.sql -o ./lint_report.md

      - name: Detect Breaking Changes
        run: schemaflow diff -b v1.sql -t v2.sql -o ./diff_report.md --fail-on-breaking
